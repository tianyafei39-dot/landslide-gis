# landslide-gis
基于机器学习的滑坡易发性评价 WebGIS 平台
基于 Vue3 + Element Plus + Leaflet + FastAPI + Scikit-learn 构建的全流程GIS工程应用，聚焦滑坡地质灾害易发性智能评价与可视化预警，完成从需求分析到项目总结的完整工程落地

✅ 真实GIS工程全生命周期实践 | ✅ 机器学习滑坡评价 | ✅ WebGIS可视化渲染 | ✅ AI协同开发（代码生成占比≥50%）

📌 项目简介
本项目依托题目2真实GIS工程全流程开发考核任务落地实现，是一套面向地质灾害防治的智能化滑坡易发性评价WebGIS平台。项目严格遵循GIS工程项目全生命周期开发规范，基于真实地理空间数据，结合机器学习算法完成滑坡灾害易发性分级、预测分析与动态可视化预警，实现了地质灾害评价的智能化、可视化、网络化。
项目以 AI协同开发 为核心特色，整体代码AI生成占比≥50%，兼顾开发效率与系统稳定性，完整落地需求分析、方案设计、功能开发、测试优化、项目部署、复盘总结全流程工程实践，有效解决传统滑坡评价方式可视化差、计算效率低、成果展示不直观、无法实时预警的行业痛点，可为区域滑坡灾害风险评估、防灾减灾规划提供数字化技术支撑。
✨ 核心功能
平台聚焦滑坡智能评价与GIS可视化核心场景，主打机器学习异步训练与滑坡风险动态预警渲染两大核心能力，配套完善的GIS基础操作功能，具体如下：
1. 机器学习异步训练模块（核心AI能力）
基于 Scikit-learn 机器学习框架搭建滑坡易发性评价模型体系，支持多因子滑坡样本数据训练、模型评估与预测，采用异步任务机制规避前端阻塞问题。系统支持导入高程、坡度、坡向、植被覆盖、水系距离、地质岩性等多维度真实GIS空间因子数据，可自主完成数据清洗、特征筛选、样本划分、模型训练与精度验证，输出滑坡易发性分级模型。异步任务架构支持多任务排队训练、训练进度实时回显、训练日志记录、模型权重保存与复用，大幅提升灾害评价模型迭代效率。
2. 滑坡风险动态预警渲染模块（核心GIS能力）
基于 Leaflet 开源GIS地图引擎实现滑坡易发性结果的动态可视化渲染，是平台核心展示与应用能力。系统可将机器学习模型输出的滑坡易发性数据，按高、中、低风险等级进行分级配色渲染，支持地图缩放、平移、点位查询、图层显隐、矢量边界高亮等GIS基础操作。同时实现动态预警更新，模型训练完成、数据更新后可自动刷新地图渲染结果，实时展示区域滑坡风险分布格局，支持风险点位弹窗详情展示、预警区域标注、可视化成果导出，让抽象的地质灾害评价数据直观化、可视化。
3. 配套基础功能
- 地图基础操作：缩放、平移、测距、测面积、图层管理
- 空间数据管理：真实GIS矢量数据、栅格数据导入与解析
- 模型管理：模型训练记录查询、精度指标展示、模型复用
- 数据可视化：风险统计图表、分级图例、评价结果导出
🛠️ 技术栈
项目采用前后端分离架构，轻量化、高性能、易部署，适配GIS空间计算与AI模型训练场景：
前端技术
- Vue3：主流前端框架，组合式API提升代码复用性与项目可维护性
- Element Plus：企业级UI组件库，快速搭建规范、简洁的后台管理界面
- Leaflet：轻量级开源WebGIS地图引擎，高性能支持空间数据渲染与地图交互
后端技术
- FastAPI：高性能Python后端框架，支持异步接口、自动接口文档，适配AI任务异步处理
- Scikit-learn：经典机器学习框架，用于滑坡因子建模、模型训练与易发性预测
🏗️ 技术架构说明
系统采用前后端分离三层架构，分为前端可视化层、后端服务层、数据与算法层，层级解耦清晰，便于开发迭代与功能拓展，完全适配GIS+AI融合业务场景：
1. 前端可视化层
基于Vue3 + Element Plus搭建系统整体交互界面，负责用户操作交互、地图可视化展示、任务进度展示、数据结果呈现。通过Leaflet引擎实现地理空间数据解析、图层渲染、空间交互等GIS核心能力，通过Axios对接后端API，异步获取模型训练状态、风险评价数据与空间图层数据，完成前端动态渲染与数据更新。
2. 后端服务层
基于FastAPI构建高性能异步服务，提供统一的API接口体系，包含数据上传接口、模型训练异步接口、地图数据接口、结果查询导出接口等。核心支持异步任务调度，解决机器学习训练耗时较长导致的接口阻塞问题，保障系统运行流畅，同时实现接口权限控制、请求校验、日志记录等基础服务能力。
3. 数据与算法层
为系统核心能力支撑层，包含真实GIS空间数据与机器学习算法模型两部分。数据层存储高程、坡度、植被、地质等滑坡评价核心空间数据；算法层基于Scikit-learn构建滑坡易发性评价模型，实现数据预处理、特征工程、模型训练、精度验证、风险预测等核心AI计算能力，为前端可视化预警提供数据支撑。
