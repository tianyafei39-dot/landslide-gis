## 1 引言

### 1.1 项目背景

本项目遵循软件全生命周期开发流程（需求→设计→开发→测试→部署→总结），基于 Vue3 + Element Plus + Leaflet + FastAPI + Scikit-learn，结合真实滑坡空间地理数据，开发滑坡易发性评价 WebGIS 平台。项目采用 AI 协同开发，AI 生成代码占比≥50%。

### 1.2 设计目标

1. 采用前后端分离架构，模块解耦，便于独立开发调试；
2. 实现 GIS 空间数据解析、机器学习异步训练、滑坡风险动态可视化渲染；
3. 保证空间数据投影统一、空间采样逻辑正确；
4. 接口标准化，方便前后端联调；
5. 系统轻量化，可在单机本地部署演示。

### 1.3 范围

本设计覆盖前端 WebGIS 可视化模块、后端 API 服务、异步任务调度、GIS 预处理模块、机器学习建模模块。不含用户登录、权限管理、多用户并发生产级功能。

## 2 系统总体架构

**三层架构：前端可视化层 — 后端服务层 — 数据与算法层**

1. **前端可视化层**
Vue3 + Vite + Element Plus + Leaflet。负责页面交互、地图展示、图层渲染、训练进度展示、结果可视化、参数配置。通过 Axios 调用后端 RESTful API，轮询异步任务状态。
2. **后端服务层**
FastAPI 作为 Web 服务框架，提供文件上传、任务创建、进度查询、结果获取接口；使用后台线程实现**异步训练任务**，避免长时间模型训练阻塞 HTTP 请求；处理文件校验、异常捕获、日志输出。
3. **数据与算法层**

- GIS 预处理模块：读取 tif 栅格、shp 矢量，栅格重采样、投影校验、因子提取、归一化、正负样本采样；
- 机器学习模块：基于 Scikit-learn 构建评价模型（随机森林），训练、交叉验证、模型保存、生成滑坡易发性栅格；
- 数据存储：本地文件存储（上传 tif/shp、训练模型文件、输出易发性 tif 结果），不引入数据库，简化工程。

> 
> 数据流转：
> 用户上传 GIS 因子 + 滑坡样本 → 后端 GIS 预处理 → 生成特征数据集 → 启动异步模型训练 → 模型输出易发性栅格 → 前端 Leaflet 加载栅格图层，动态分级渲染预警图。

## 3 模块详细设计

### 3.1 前端模块划分

1. 地图模块：Leaflet 初始化、底图加载、栅格图层渲染、图例、点位查询、图层显隐控制；
2. 数据上传模块：tif/shp 文件上传、文件列表展示；
3. 模型训练模块：模型参数选择、启动训练、进度条轮询展示、训练指标展示；
4. 成果展示模块：风险分级配色渲染、成果预览、图片导出；
5. 辅助 UI 模块：Element Plus 弹窗、提示消息、任务历史列表。

### 3.2 后端模块划分

1. `main.py`：FastAPI 入口，路由注册、跨域配置；
2. `gis_preprocess.py`：GIS 栅格矢量读取、因子预处理、样本采样；
3. `train_task.py`：异步任务管理，后台线程、进度保存、任务状态维护；
4. `model.py`：sklearn 模型训练、评估、预测、生成易发性栅格；
5. 文件管理模块：文件接收、存储、文件格式校验。

## 5 数据设计

### 5.1 文件存储设计

- `backend/uploads/`：用户上传原始 tif、shp；
- `backend/models/`：保存训练完成的 sklearn 模型（joblib 格式）；
- `backend/result/`：输出滑坡易发性栅格 tif；


### 5.2 训练数据集结构

每一个栅格像元作为一条样本：
特征：高程、坡度、坡向、NDVI、距断层距离、距水系距离、岩性编码
标签 label：1（滑坡点） / 0（非滑坡采样点）

### 5.3 输出成果

滑坡易发性栅格，值域 [0,1]，分为 5 级：

1. 极低易发：0~0.2
2. 低易发：0.2~0.4
3. 中易发：0.4~0.6
4. 高易发：0.6~0.8
5. 极高易发：0.8~1.0

## 6 GIS 空间逻辑设计

1. 所有输入栅格统一投影为 WGS84（EPSG:4326），和 Leaflet 地图投影匹配；
2. 所有因子栅格重采样至相同分辨率、相同范围；
3. 根据滑坡矢量点在多因子栅格上采样，提取对应像元特征；
4. 预测输出栅格与原始因子栅格空间范围、分辨率保持一致，保证地图渲染不偏移。

## 7 异常设计

1. 文件异常：非 tif/shp、文件损坏、投影不一致，返回前端提示；
2. 数据异常：因子图层数量不足、滑坡样本过少，终止训练；
3. 训练异常：内存不足、模型报错，更新任务状态为失败并返回错误信息。

## 8 部署环境设计

后端：Python3.9+，FastAPI、rasterio、geopandas、scikit-learn、joblib
前端：Node.js 16+，Vite、Vue3、Element Plus、Leaflet
