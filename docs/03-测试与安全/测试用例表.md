## 1 引言

### 1.1 编写目的

本文档定义系统功能、异常、安全与 GIS 空间逻辑的测试用例，覆盖《需求分析说明书》全部高优先级需求，作为测试执行与《系统测试报告》的依据。

### 1.2 用例编号规则

`TC-{模块}-{序号}`，模块缩写与需求文档一致：AUTH 认证 / USER 用户管理 / DATA 数据管理 / TRAIN 训练 / GIS 可视化 / RESULT 成果 / AUX 辅助 / SEC 安全 / COMP 兼容部署 / CONC 并发承载。

### 1.3 测试环境

| 项 | 配置 |
|---|---|
| 操作系统 | Windows 10/11 |
| 后端 | Python 3.10+，FastAPI @ http://127.0.0.1:8000 |
| 前端 | Node.js 18+，Vite @ http://127.0.0.1:5173 |
| 浏览器 | Chrome / Edge 最新版 |
| 测试数据 | 内置示例数据（6 因子 + 96 灾害点 + 研究区）+ 构造的异常数据 |
| 账号 | admin（管理员）、user1（普通用户，测试中新建） |

### 1.4 优先级定义

P0 = 核心链路（阻塞验收）；P1 = 重要功能/异常；P2 = 边缘场景。
