## 1 引言

### 1.1 编写目的

本文档定义"滑坡易发性评价 WebGIS 平台"的功能需求、非功能需求、数据需求、接口需求、约束条件与验收标准，作为后续系统设计、编码实现、测试验证与项目验收的依据。

预期读者：项目开发人员、测试人员、课程指导教师及项目评审人员。

### 1.2 项目背景

滑坡是常见的地质灾害类型，开展滑坡易发性评价对防灾减灾具有现实意义。传统评价工作依赖桌面 GIS 软件与离线建模脚本，流程割裂、门槛较高。本项目面向 GIS 工程实践，采用"WebGIS + 机器学习"一体化技术路线，覆盖 **数据管理 → 模型训练 → 成果渲染 → 查询导出** 的完整业务闭环，帮助用户在浏览器中完成滑坡易发性评价的全流程操作。

项目采用 AI 协同开发模式，AI 生成代码占比 ≥ 50%，并按软件全生命周期（需求 → 设计 → 开发 → 测试 → 部署 → 总结）组织交付物。

### 1.3 定义与缩写

| 术语 | 说明 |
|---|---|
| 易发性（Susceptibility） | 一定区域内滑坡发生可能性的空间量化表达，取值 0~1 |
| 因子栅格 | 参与建模的空间环境因子（DEM、坡度、NDVI 等），GeoTIFF 格式 |
| 灾害点样本 | 历史滑坡灾害点矢量（Shapefile），作为正样本（label=1） |
| 研究区 | 评价区域边界矢量（Shapefile），限定建模与统计范围 |
| 异步训练 | 训练任务在后端后台线程执行，前端轮询进度，不阻塞页面交互 |
| AUC | ROC 曲线下面积，衡量分类模型优劣的核心精度指标 |

## 2 项目概述

### 2.1 系统定位

基于真实滑坡空间地理数据的机器学习滑坡易发性评价 WebGIS 平台。前端 Vue3 + Element Plus + Leaflet，后端 FastAPI + GDAL/Rasterio + Scikit-learn，前后端分离部署，支持本地单机运行。

### 2.2 项目目标

1. 支持多源 GIS 空间因子数据的上传、解析、预处理与质量校验（投影、网格对齐）；
2. 后端异步执行机器学习模型训练，训练状态实时反馈，不阻塞前端页面；
3. 训练产出滑坡易发性模型与分级风险栅格，模型精度指标（AUC 等）可量化评估；
4. WebGIS 前端对易发性结果进行动态分级渲染、图层管理、点位查询与成果导出；
5. 系统可本地一键部署，具备基础容错与异常提示能力；
6. 验证 GIS 空间逻辑正确性（投影统一、位置无偏移），完成全工程周期文档交付。

### 2.3 系统范围

**包含：** 用户登录、数据上传与校验、示例数据一键载入、异步模型训练、易发性分级渲染、点位查询、成果导出、结果与文件删除、训练任务历史。

**不包含：** 多租户与细粒度权限体系、大规模并发生产部署、在线地图编辑、实时监测数据接入、移动端适配。

## 3 用户与角色分析

| 角色 | 说明 | 主要操作 |
|---|---|---|
| 普通用户（user） | 业务操作人员，如地灾相关技术人员 | 登录、上传数据、发起训练、查看渲染结果、点查询、导出成果 |
| 管理员（admin） | 系统维护人员 | 具备普通用户全部能力，负责账号管理与系统维护 |

系统采用单机部署，支持有限并发（训练并发受闸门控制并排队，查询/登录经 WAL 与压缩优化），不面向大规模生产级并发；角色区分用于满足基本的访问控制要求。

| FR-DATA-05 | 提供因子投影与网格对齐校验能力：校验各因子栅格的坐标系、分辨率、行列数与空间范围是否一致，输出校验结论 | 高 |
| FR-DATA-06 | 提供"载入示例数据"能力：一键装配内置 6 个因子栅格（DEM、坡度、坡向、平面曲率、剖面曲率、NDVI）+ 96 个滑坡灾害点 + 研究区边界，并返回投影校验结果 | 高 |
| FR-DATA-07 | 支持移除已上传的因子/样本/研究区：用户上传文件同步删除服务端文件；内置示例数据受保护，仅从前端列表移除，不允许通过接口删除 | 高 |
| FR-DATA-08 | 上传阶段进行格式校验（扩展名、文件完整性），非法文件给出错误提示 | 高 |
| FR-DATA-09 | 支持上传自定义模型文件（.joblib / .pkl，sklearn 分类模型），保存至用户专属目录并返回路径 | 高 |
| FR-DATA-10 | 上传文件按用户隔离存储（uploads/{user_id}/），文件名清洗防路径穿越；非 admin 仅能使用本人目录或示例数据中的文件 | 高 |

### 4.3 机器学习训练模块（TRAIN，核心）

| 编号 | 需求描述 | 优先级 |
|---|---|---|
| FR-TRAIN-01 | 提供训练发起入口，可选择模型类型：随机森林（Random Forest）、逻辑回归（Logistic Regression），默认随机森林 | 高 |
| FR-TRAIN-02 | 训练任务在后端后台异步执行（线程），接口立即返回任务 ID，长时间训练不阻塞 HTTP 请求 | 高 |
| FR-TRAIN-03 | 前端轮询训练状态接口，实时展示进度条，阶段覆盖：采样 → 训练 → 评估 → 渲染 | 高 |
| FR-TRAIN-04 | 训练前完成样本采样：滑坡点为正样本（label=1），研究区内随机采样非滑坡点为负样本（label=0）；在多因子栅格上按像元位置提取特征 | 高 |
| FR-TRAIN-05 | 训练完成后输出模型精度指标，至少包括 AUC，并支持准确率、召回率等辅助指标 | 高 |
| FR-TRAIN-06 | 保存训练模型（joblib 格式）与易发性分级栅格结果（GeoTIFF，含投影信息） | 高 |
| FR-TRAIN-07 | 训练失败（样本不足、因子缺失、模型报错等）时任务状态置为失败，并向前端返回可读的错误信息 | 高 |
| FR-TRAIN-08 | 训练结果栅格值域 0~1，按固定阈值划分为 5 级风险 | 高 |
| FR-TRAIN-09 | 支持"搭积木"式自定义建模：预处理（标准化/归一化/无）× 降维（PCA/无）× 算法（随机森林/SVM/逻辑回归）自由组合为 sklearn Pipeline | 高 |
| FR-TRAIN-10 | 支持超参数调节：负样本比例、决策树数量、逻辑回归 C、SVM 的 C 与核函数；参数须真实作用于训练过程（提交值与落盘模型属性一致） | 高 |
| FR-TRAIN-11 | 支持上传模型直接评价：加载用户上传的 joblib 模型跳过训练，仍输出精度指标与全区预测；模型须含 predict_proba，文件缺失须显式报错 | 高 |
| FR-TRAIN-12 | 输出特征重要性（各因子贡献度，降序），供成因分析，图表可导出 PNG；无法提取时不阻断主流程 | 中 |
| FR-TRAIN-13 | 非 admin 用户发起训练时校验全部文件路径（因子/样本/研究区/自定义模型）归属，越权拒绝 | 高 |

风险分级定义（固定阈值，保证分级范围稳定）：

| 等级 | 值域 | 配色 |
|---|---|---|

| 低易发 | 0.2 ~ 0.4 | 黄绿色系 |
| 中易发 | 0.4 ~ 0.6 | 黄色系 |

## 6 数据需求

### 6.1 输入数据

| 数据类型 | 格式 | 说明 |
|---|---|---|
| 因子栅格 | GeoTIFF（.tif） | 须带投影坐标（推荐统一投影，如 EPSG:32647）；示例数据含 DEM、Slope、aspect、plan_cur、curvature、NDVI 共 6 个因子，完整因子库另含 NDWI/MNDWI/NDBI、土地利用、岩性、距断层/水系/道路距离、降水量等 |
| 灾害点样本 | Shapefile（.zip） | 历史滑坡灾害点，示例数据 96 个点，label=1 |
| 研究区边界 | Shapefile（.zip） | 限定采样与统计范围 |

### 6.2 训练数据集

每个采样点为一条样本：

- **特征**：各因子栅格在该点位置的像元值（高程、坡度、坡向、曲率、NDVI 等）；
- **标签 label**：1（滑坡灾害点）/ 0（非滑坡采样点）。

### 6.3 输出数据

| 输出 | 格式 | 说明 |
|---|---|---|
| 易发性栅格 | GeoTIFF | 值域 0~1，带投影，与输入因子空间范围、分辨率一致 |
| 模型文件 | joblib | 训练好的 sklearn 模型 |
| 渲染图层 | PNG + 边界/图例/统计 JSON | 供前端地图叠加与图例展示 |
| 成果图片 | PNG | 含风险图、图例、分级占比、模型指标的合成图 |

### 6.4 数据存储

- `data/raw/`：内置示例 GIS 数据（受保护）；
- `backend/uploads/`：用户上传文件；
- `backend/models/`：训练模型文件；
- `backend/result/`：训练结果栅格、渲染 PNG、GeoJSON；
- `backend/sql_app.db`：SQLite，用户账号数据。

## 7 GIS 空间逻辑需求

空间逻辑正确性是本项目的硬性要求（对应验收项）：

1. **投影统一**：所有输入因子栅格须为同一投影坐标系；与前端地图叠加时统一转换到 WGS84（EPSG:4326）经纬度；
2. **网格对齐**：所有因子栅格重采样至相同分辨率、相同行列数、相同空间范围，采样前须通过投影与网格对齐校验；
3. **采样准确**：滑坡点/非滑坡点按坐标在各因子栅格上定位同一像元提取特征，保证特征-标签空间对应正确；
4. **成果一致**：预测输出栅格与输入因子栅格空间范围、分辨率保持一致；前端渲染图层与底图套合无明显偏移；
5. **统计口径**：分级面积占比基于原始投影栅格统计，避免重采样造成统计偏差。

## 9 约束与假设

1. 本系统为课程工程实践项目，不面向大规模并发生产使用；已实现最小并发承载（训练闸门排队 + WAL + 压缩缓存），满足多用户同时试用；
2. 只支持单区域、小范围栅格建模，数据规模以单机内存可承载为限；
3. 训练算法限定 sklearn 范围（随机森林、逻辑回归），不涉及深度学习；
4. 数据存储以本地文件 + SQLite 为主，不引入大型数据库；
5. 假设用户具备基本 GIS 数据常识（投影、Shapefile 组成等）；
6. 假设运行环境可联网获取底图瓦片（离线时降级为无底图模式）。
