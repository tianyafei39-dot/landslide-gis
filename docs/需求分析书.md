# 基于机器学习的滑坡易发性评价 WebGIS 平台 —— 需求分析说明书

## 1 项目概述

本项目为真实 GIS 工程全流程开发——工程实践项目，完成从需求、设计、开发、测试、部署到总结的完整软件生命周期。平台采用 Vue3+Element Plus+Leaflet+FastAPI+Scikit-learn 技术栈，利用真实滑坡空间地理数据，构建机器学习滑坡易发性评价模型，实现模型异步训练、滑坡风险动态预警地图渲染，完成 GIS+AI 一体化 Web 平台开发。项目开发采用 AI 协同开发模式，AI 生成代码占比≥50%。

## 2 项目目标

1. 支持多源 GIS 空间因子数据上传、解析与预处理；
2. 后端异步执行机器学习滑坡模型训练，训练状态实时反馈，不阻塞前端页面；
3. 训练得到滑坡易发性模型，输出分级风险栅格；
4. WebGIS 前端基于 Leaflet 对滑坡易发性结果进行动态分级渲染、图层管理、空间查询；
5. 系统可本地部署，具备基础容错、异常提示能力；
6. 验证 GIS 空间逻辑正确性，完成全工程周期文档交付。

## 3 功能需求

### 3.1 数据管理模块

1. 支持上传栅格 tif、滑坡样本 shp；
2. 后端读取 GIS 数据，自动提取高程、坡度、NDVI、距离因子；
3. 因子归一化、样本采样，生成机器学习训练数据集；
4. 数据预览，查看上传文件列表。

### 3.2 机器学习异步训练模块（核心需求）

1. 发起模型训练任务，任务在后台异步执行；
2. 前端轮询获取训练进度，展示进度条；
3. 支持选择随机森林 / 逻辑回归等 sklearn 模型；
4. 训练完成输出模型精度指标（AUC、准确率、召回率）；
5. 保存训练模型与滑坡易发性分级栅格结果。

### 3.3 WebGIS 动态预警渲染模块（核心需求）

1. Leaflet 加载底图，支持地图缩放、平移；
2. 加载后端返回的滑坡易发性栅格图层，按风险等级（极高 / 高 / 中 / 低 / 极低）配色动态渲染；
3. 图层开关控制，图例展示风险分级；
4. 鼠标点击地图点位，弹窗展示该位置滑坡易发性数值；
5. 评价成果图片导出。

### 3.4 系统辅助功能

1. 任务历史记录查看，查看过往训练任务与结果；
2. 错误提示：文件格式错误、数据缺失、训练失败提示。

## 4 非功能需求

1. 前后端分离架构；
2. GIS 空间逻辑：投影统一，空间位置匹配，栅格采样位置准确；
3. 性能：模型训练长时间任务不阻塞 Web 接口；
4. 兼容性：Chrome、Edge 主流浏览器；
5. 开发规范：AI 辅助代码生成，整体代码 AI 生成占比≥50%；
6. 可部署：支持本地单机部署。

## 5 数据需求

- 输入因子：DEM、坡度、坡向、NDVI、距断层距离、距水系距离、岩性；
- 样本标签：滑坡点 label=1，非滑坡采样点 label=0；
- 输出：滑坡易发性栅格，值域 0~1，划分 5 级风险。

## 6 约束与边界

1. 本系统为课程工程实践项目，不面向大规模并发生产使用；
2. 只支持单区域小范围栅格建模；
3. 不包含用户登录权限模块（简化开发，节省时间）。

## 7 验收标准

1. 完整跑通：上传 GIS 数据 → 异步训练 → 前端地图动态渲染滑坡风险；
2. 空间位置无明显偏移，风险分布符合地质常识；
3. 代码 AI 生成占比≥50%；
4. 全套工程文档齐全，可演示、可部署。
