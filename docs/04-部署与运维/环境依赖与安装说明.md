|---|---|

| 版本 | V1.2 |

| 适用对象 | 首次部署人员、开发环境搭建人员 |

---

## 1 概述

本文档说明系统运行所需的软硬件环境、Python/Node.js 依赖清单与首次安装步骤。按本文档完成安装后，即可使用《系统部署与启动手册》启动系统。

**技术栈总览：** 前端 Vue3 + Vite + Element Plus + Leaflet；后端 FastAPI + GDAL/Rasterio + Scikit-learn；数据库 SQLite。

---

## 2 硬件与操作系统

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位）；Linux/macOS 理论可运行（启动脚本为 Windows 批处理，需手动启动） |
| CPU | 双核及以上（随机森林训练利用多核 n_jobs=-1） |
| 内存 | ≥ 8 GB（推荐 16 GB；训练时需容纳多波段栅格数组，示例数据约需 2~3 GB 峰值） |
| 磁盘 | ≥ 5 GB 可用空间（Python 环境 + Node 依赖 + 数据与产物） |
| 显示器 | 1920×1080 及以上（WebGIS 界面较宽） |
| 网络 | 首次安装需联网下载依赖包；运行时联网可加载在线底图瓦片（离线可降级无底图模式） |

## 3 基础软件环境

| 软件 | 版本要求 | 检查命令 | 说明 |
|---|---|---|---|
| Python | 3.11 及以上（实测 3.14.6） | `python --version` | 官方发行版均可；需勾选加入 PATH；锁定依赖 SQLAlchemy 2.1.x 需 ≥3.11 |
| Node.js | 18 及以上 | `node --version` | 含 npm；推荐 LTS 版本 |
| npm | 随 Node.js | `npm --version` | 前端依赖安装 |
| 浏览器 | Chrome / Edge 最新版 | — | 主流浏览器即可 |

> Python 与 Node.js 安装包可在各自官网下载；安装 Windows 版 Python 时务必勾选 **Add python.exe to PATH**。

## 4 后端环境与依赖安装

### 4.1 创建 Python 虚拟环境（首次一次）

在项目根目录（`D:\my\landslide-webgis-platform`）执行：

```powershell
cd backend
python -m venv venv
```

> `backend\venv` 文件夹已存在则跳过本节（虚拟环境随项目交付，可直接复用）。

### 4.2 安装依赖包（首次一次）

```powershell
cd backend
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

> 若 venv 已存在但缺包（如换机器后报 ModuleNotFoundError），同样执行本条命令补齐。

### 4.3 依赖清单（requirements.txt）

> 自 V1.2 起依赖清单改为**精确版本锁定**（`==`，基准为实测通过的 venv 环境），保证本地安装与 Docker 镜像构建可复现；升级任一依赖前须先回归测试（尤其 bcrypt 与 scikit-learn）。

| 包 | 版本（锁定） | 用途 |
|---|---|---|
| fastapi | == 0.143.0 | Web 框架 |
| uvicorn[standard] | == 0.54.0 | ASGI 服务器 |
| pydantic | == 2.14.0 | 请求/响应模型校验 |
| python-multipart | == 0.0.32 | 文件上传解析 |
| passlib | == 1.7.4 | 口令哈希（不带 [bcrypt] extra，避免解析器拉新版 bcrypt） |
| bcrypt | == 4.0.1 | passlib 后端（**必须 <4.1**，4.1+ 与 passlib 不兼容，见 EC-04） |
| PyJWT | == 2.15.1 | JWT 令牌签发校验 |
| SQLAlchemy | == 2.1.8 | ORM（SQLite） |
| python-dotenv | == 1.2.4 | .env 配置加载 |
| rasterio | == 1.5.2 | 栅格读写、重投影（GDAL 绑定，manylinux 轮子） |
| geopandas | == 1.2.0 | 矢量处理 |
| shapely | == 2.2.0 | 几何运算 |
| pyproj | == 3.8.0 | 坐标投影转换（gis_preprocess 直接引用） |
| scikit-learn | == 1.9.1 | 随机森林 / 逻辑回归 / SVM / Pipeline（训练与加载版本须一致，跨版本加载 joblib 告警） |
| joblib | == 1.6.0 | 模型持久化 |
| numpy | == 2.5.3 | 数值计算 |
| pandas | == 3.0.6 | 数据表处理 |
| pillow | == 13.0.0 | PNG 渲染与合成 |

**安装注意事项：**

1. `rasterio` 依赖 GDAL 二进制库，Windows 下 pip 一般直接拉取预编译轮子；若安装失败，优先升级 pip：`python -m pip install -U pip` 后重试；
2. `bcrypt==4.0.1` 为刻意约束：passlib 与 bcrypt 4.1+ 存在兼容问题，请勿随意升级；
3. 全程使用 venv 内的 Python（`.\venv\Scripts\python.exe`），避免装到系统全局环境；
4. Docker 镜像构建直接使用本清单（`docker/Dockerfile.backend`），版本与本地环境严格一致。

## 5 前端环境与依赖安装

### 5.1 安装 npm 依赖（首次一次）

```powershell
cd frontend
npm install
```

> `frontend\node_modules` 已存在则跳过。

### 5.2 依赖清单（package.json）

| 包 | 版本 | 用途 |
|---|---|---|
| vue | ^3.5.42 | 前端框架 |
| vue-router | ^4.6.5 | 路由与登录守卫 |
| element-plus | ^2.14.7 | UI 组件库 |
| leaflet | ^1.9.4 | 地图引擎 |
| axios | ^1.21.0 | HTTP 请求 |
| vite | ^8.3.0（dev） | 构建与开发服务器 |
| @vitejs/plugin-vue | ^6.0.8（dev） | Vue 插件 |

> 分离部署模式下**不需要** `npm run build`，`npm run dev` 直接运行源码、热更新；仅单服务备选模式才需构建（见部署手册）。

## 6 配置文件准备（.env）

后端启动前需存在 `backend\.env`（项目交付时已含）。各变量含义与默认值详见《系统部署与启动手册》第 4 章；此处仅列出最小必配项：

| 变量 | 必配 | 说明 |
|---|---|---|
| JWT_SECRET | 是 | 令牌签名密钥，缺失则后端启动直接报错退出 |
| ADMIN_USERNAME / ADMIN_PASSWORD | 否 | 初始管理员（默认 admin / admin123456，仅首次建号生效） |
| TRAIN_MAX_CONCURRENT | 否 | 训练并发上限（默认 2，V1.2），超出任务排队；详见《系统部署与启动手册》4.1 |

## 7 环境验证

安装完成后逐项验证：

| 验证项 | 命令/操作 | 预期 |
|---|---|---|
| Python 版本 | `python --version` | 3.11+（实测 3.14.6） |
| Node 版本 | `node --version` | 18+ |
| 后端依赖完整 | `cd backend` 后 `.\venv\Scripts\python.exe -c "import fastapi, rasterio, geopandas, sklearn"` | 无 ModuleNotFoundError |
| 前端依赖存在 | `cd frontend` 后 `test-Path node_modules` | True |
| .env 就绪 | 检查 `backend\.env` 含 JWT_SECRET | 文件存在 |

全部通过后，进入《系统部署与启动手册》。

## 8 卸载/重装

| 场景 | 操作 |
|---|---|
| 重装后端依赖 | 删除 `backend\venv` → 重做 4.1、4.2 |
| 重装前端依赖 | 删除 `frontend\node_modules` → 重做 5.1 |
| 重置管理员 | 停止服务 → 删除 `backend\sql_app.db`（注意会清空全部账号）→ 重启后自动重建并初始化管理员 |
| 清空训练结果 | 停止服务 → 清空 `backend\result\`、`backend\uploads\`、`backend\models\` |
